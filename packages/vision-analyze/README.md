# tinkerdesk-plugin-vision-analyze

TinkerDesk 插件：视觉分析（Vision Analyze）——对图片进行多模态理解 / 描述 / 问答。

> npm 包：`tinkerdesk-plugin-vision-analyze`

## 在线安装（推荐）

TinkerDesk 现已支持**插件市场在线安装**：

1. 打开「插件设置」→ 点「**安装插件**」
2. 选「**插件市场**」→ 搜索 `vision-analyze`
3. 点安装 → 自动下载 + 生效

或在命令行：

```bash
npm install tinkerdesk-plugin-vision-analyze
```

## 能力

- `vision:analyze`（加载图片并理解内容 / 生成描述 / 回答视觉问题）

## 使用

对话中含图片 / 粘贴图片后，调用视觉分析能力即可理解图片内容。

## 本地安装（旧方式）

手动下载插件包 → 插件设置「安装插件」→ 选文件夹 / `.zip` → 安装。
